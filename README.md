# 🚀 Frontend Wizards Stage 1 — Multi-Page Application

## 📌 Overview
This project is part of the **Frontend Wizards Challenge (Stage 1)**.  
It expands the Stage 0 single-page profile card into a **three-page web application**:
- **Home** (Profile Card)
- **About Me** (Reflection Page)
- **Contact Us** (Form with Validation)

The project follows principles of **semantic HTML**, **accessibility**, and **responsive design**.

---

## 🧭 Features
### 🏠 Home (index.html)
- Profile card from Stage 0.
- Linked navigation to other pages.
- Clean, minimal design.

### 👤 About Me (about.html)
- Sections include:
  - Bio
  - Goals in this program
  - Areas of low confidence
  - Note to future self
  - Extra thoughts
- Uses `<main>` and `<section>` for semantic structure.

### 💬 Contact Us (contact.html)
- Form with client-side validation using JavaScript.
- Error and success messages handled dynamically.
- Accessibility features:
  - Linked `<label>`s and `aria-describedby`.
  - Keyboard-navigable form.
  - `aria-live` for dynamic text.

---

## 💡 Accessibility
- Semantic HTML (`main`, `section`, `header`, `nav`).
- Color contrast ensured for readability.
- Fully keyboard accessible.
- Form uses ARIA roles and attributes for screen readers.

---

## 📱 Responsiveness
- Works on mobile, tablet, and desktop.
- Mobile menu toggle added for small screens.
- Layout adapts using CSS Flexbox and media queries.
